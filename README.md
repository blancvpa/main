# Static Site Mirror

Этот проект подготовлен для развертывания на статических хостингах (GitHub Pages, Cloudflare Pages и др.).

## Структура
- `index.html` — главная страница сайта.
- `assets/` — папка со всеми ресурсами (изображения, стили, скрипты).
- `.nojekyll` — файл для GitHub Pages, отключающий обработку Jekyll.

## Инструкции по деплою

### GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите все файлы из этой папки в репозиторий.
3. Перейдите в **Settings** -> **Pages**.
4. В разделе **Build and deployment** выберите ветку `main` (или ту, куда вы загрузили файлы) и папку `/ (root)`.
5. Нажмите **Save**. Сайт будет доступен по адресу `https://<username>.github.io/<repo-name>/`.

### Cloudflare Pages
1. Зайдите в панель управления Cloudflare.
2. Перейдите в **Workers & Pages** -> **Pages**.
3. Нажмите **Connect to Git** или **Upload assets**.
4. Если загружаете напрямую (Upload assets), просто перетащите файлы из этой папки.
5. Если через Git, выберите репозиторий. В настройках сборки (Build settings) оставьте поля пустыми (так как это статический HTML).
6. Нажмите **Deploy**.

## Зеркала сайта
Для создания зеркал просто повторите процесс деплоя на разные платформы или под разными доменами/именами репозиториев.
